# 🎧 Animated Earbuds Website

A premium, immersive earbuds website designed with cinematic product animations, smooth scrolling, and interactive visual effects.

The website focuses on creating a modern product experience where the earbuds come alive through scroll-based animations.

## ✨ Features

- 🎧 Premium earbuds product showcase
- 🌀 Scroll-driven product animations
- 🎬 Cinematic visual transitions
- 🔍 Interactive product presentation
- ✨ Smooth hover effects
- 📱 Responsive design
- 🖥️ Modern desktop experience
- ⚡ Smooth and optimized animations
- 🎨 Minimal and premium UI
- 🖱️ Interactive micro-interactions

## 🛠️ Tech Stack

- HTML5
- CSS3
- JavaScript
- GSAP
- GSAP ScrollTrigger
- Vite
- JavaScript Animation APIs

## 🎯 Concept

The website is designed around a cinematic product storytelling concept.

Instead of presenting the product through a traditional ecommerce layout, the user discovers the earbuds through movement and scrolling.
